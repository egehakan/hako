# Preview skill: learnings

General lessons from earlier runs, read at the start of every run. One entry per lesson: a dated
line with the situation and an indented line with the fix. Add or update entries only through
`preview.mjs learn --situation "…" --fix "…"`, which replaces an entry about the same situation
instead of adding a second one. Keep them general: no paths, project names or secrets (facts about
one project go into its profile with `profile note`).
